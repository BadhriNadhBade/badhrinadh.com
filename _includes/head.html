Choosing Classic in the control panel is remembered (desk.shell = classic), and every later visit to a Desk page that has a Classic copy is sent on to it here, before anything paints — with replace(), so Back doesn't land you on a Desk page that only bounces you forward again. Only two things change that choice: the panel, and the ✦ in Classic's corner, which links to the Desk page with ?shell=desk. That param is stored and then removed from the address bar (other params and the hash kept), so it doesn't end up in bookmarks or copied links. Opening a /classic/ link directly changes nothing: Classic runs none of our JavaScript, so someone sent a Classic link still gets Desk on their next Desk visit, unless they picked Classic themselves. It can't loop. The redirect needs page.classic_url, which the plugin only gives Desk pages that have a copy, and it's refused if the target isn't under /classic/ or if we're already there. The 404 does have a copy: an unknown /foo is served the Desk 404, which sends Classic readers on to /classic/404 (a real file); an unknown /classic/x is served the Desk 404 at that path, and the already-there check stops it. ?shell=desk wins outright, so Classic's ✦ always lands on Desk even when the store still says Classic. Then it applies a stored appearance, accent and wallpaper before the first paint, so choosing Dark doesn't flash a light page on every navigation. Deliberately inline and deliberately tiny. The allowed values and the defaults come from _data/desk.yml, the same file assets/desk.js is built from, so the two can't drift apart: a value one of them accepts is a value the other accepts. jsonify emits them as JS literals. 'auto' stays spelled out below because it isn't a list entry so much as a meaning — no data-theme at all, so desk.scss follows the OS.
